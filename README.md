# Detective Game

Кооперативный онлайн-детектив на 6–10 человек, партия около 30 минут. Среди игроков есть убийца и его сообщник, остальные ищут обоих по уликам и рассказам. Говорят в Discord голосом, сайт держит карточки, улики, карты действий и голосование. Без сборки: Node.js, Express, Socket.IO и обычный HTML/CSS/JS.

## Запуск

```bash
npm install
ADMIN_KEY=ваш-пароль npm start      # http://localhost:3000
```

- `PORT` — порт (по умолчанию 3000).
- `ADMIN_KEY` — пароль админки. Если не задан, генерируется при старте и печатается в консоль.
- `DATA_DIR` — где лежат `cases.json` (архив дел) и `stats.json` (статистика сезона). По умолчанию `./data`.

Комнату можно открыть на главной, остальные заходят по коду или по ссылке `/r/КОД`.

## Вход, возврат в игру, выход

- **Без входа.** Достаточно имени. Игрок опознаётся по токену браузера, поэтому после обрыва связи, обновления страницы или закрытой вкладки он возвращается на своё место. Другое устройство без входа не подойдёт.
- **Discord и Google.** Вошедший игрок опознаётся по аккаунту и возвращается на своё место с любого устройства. Гость, который вошёл в аккаунт уже сидя в комнате, не теряет место.
- **«Вы в игре».** Если игрок на главной странице, а место за ним закреплено, сверху показан блок с кнопками «Переподключиться» и «Выйти из партии». Пока игрок на главной, за него ходит автопилот.
- **Выход.** Крестик в игре предлагает «На главную, место сохранить» или «Покинуть партию насовсем». Выйти насовсем можно в любой момент, например, после исключения: игрок сразу может зайти в другую комнату.
- **Одна комната на человека.** Открыть или занять другую комнату можно только выйдя из текущей, сайт предложит выбрать. Это относится и к комнате с законченной партией.
- **Закрытие комнаты.** По окончании ведущий нажимает «Закрыть комнату», и все игроки освобождаются. Без этого они остаются привязанными к комнате, пока не выйдут сами (пустая комната с законченной партией закрывается через 30 минут).

### Настройка входа

Вход включается переменными окружения. Без них сайт работает по нику.

```bash
PUBLIC_URL=https://ваш-домен            # адрес сайта, нужен для адресов возврата
DISCORD_CLIENT_ID=… DISCORD_CLIENT_SECRET=…
GOOGLE_CLIENT_ID=…  GOOGLE_CLIENT_SECRET=…
DISCORD_SERVER_URL=https://discord.gg/…   # приглашение на ваш сервер: строка «Нет компании?» на главной (без неё строки нет)
SESSION_SECRET=…                        # необязательно: ключ подписи сессий; без него создаётся DATA_DIR/session.key
```

При старте сервер печатает адреса возврата. Их нужно внести у провайдера: `PUBLIC_URL/auth/discord/callback` в Discord Developer Portal (OAuth2, Redirects, scope `identify`) и `PUBLIC_URL/auth/google/callback` в Google Cloud Console (клиент OAuth «Веб-приложение», scope `openid profile`). Сессия лежит в подписанной HttpOnly-куке на 30 дней. `AUTH_DEV=1` включает тестовый вход под любым именем, только для проверок.

## Страницы и документы

Шапка ведёт в «Правила» (`#/rules`) и «Контакты» (`#/contacts`). В подвале строка «© 2026 Detective. Все права защищены. Копирование материалов сайта запрещено.», ссылки на «Политику конфиденциальности» (`#/privacy`, нужна для входа через Google) и «Соглашение о cookie» (`#/cookies`) и почта для связи. При первом визите снизу появляется плашка про cookie, после «Хорошо» она больше не показывается (`detective.cookies` в хранилище браузера). Тексты лежат в `public/js/pages.js`, короткие адреса `/rules`, `/contacts`, `/privacy`, `/cookies` редиректят на них. Почта берётся из `CONTACT_EMAIL`, по умолчанию `support@detective-game.org`. Пользовательского соглашения и оферты на сайте нет по решению владельца.

Профиль: вошедший через Discord или Google нажимает на свою плашку в шапке и задаёт имя для игры (2–18 знаков) или возвращает имя из сервиса. Имя хранится по аккаунту в `DATA_DIR/profiles.json` и одинаково на всех устройствах (`POST /api/profile`). Там же кнопка выхода.

## Защита

`server/security.js`: заголовки (CSP без чужих скриптов, nosniff, запрет рамки, HSTS на https), лимит 10 действий в секунду на сокет, не больше 30 подключений с адреса (`MAX_CONN_PER_IP`), блокировка подбора пароля админки на 15 минут после 5 попыток, потолок комнат (`MAX_ROOMS`). Токен аккаунта подписывается секретом сервера, токен гостя проверяется по виду и не может начинаться с `acc-`. Имена чистятся от невидимых символов, не повторяются в комнате и не могут быть `__proto__` или `constructor`. В боевом режиме (`NODE_ENV=production`) сервер не стартует без длинного `ADMIN_KEY`, с `AUTH_DEV=1` или без https в `PUBLIC_URL`. Проверка: `node scripts/test-security.js`. Чек-лист запуска: `docs/release.md`, целевые цифры: `docs/metrics.md`.

## Как идёт партия

Ведущий всегда один. Он создаёт комнату, выбирает пак дел и листает раунды кнопкой «Дальше». Ведущий играет наравне со всеми. Если он пропал больше чем на 45 секунд, ведение переходит к другому живому игроку, а передать его можно и вручную (★ в лобби).

Партия: вводная (карточка и роль) → 4 раунда → дело закрыто.

Каждый обычный раунд:

1. **Улика.** Открывается новая улика (в финале сразу все оставшиеся).
2. **Круг рассказов.** Игроки по очереди, по кругу с места, которое сдвигается каждый раунд. Говорящий открывает один пункт своей карточки (безопасный или рискованный секрет) и рассказывает о себе голосом. Профессию и особенность сам он открывает только одну из двух: вторую раскроют «Обыск», «Показания» или исключение (правило `oneOfTwo`). Остальные слушают. Кнопка «Рассказ закончен» или пропуск ведущего.
3. **Обсуждение.** Свободный разговор и карты: «Обыск», «Показания», «Очная ставка», «Подмена улики», «Экспертиза». К допросу переходит ведущий; в партии по таймерам есть кнопка «Готово к допросу».
4. **Допрос.** В порядке рассказов каждый выбирает одного игрока (кроме выбывших) и задаёт ему вопрос голосом, на ответ 30 секунд (в режиме ведущего отсчёт запускает ведущий, и к следующему вопросу переходит только он; по таймерам отвечающий может нажать «Ответ дан»). «Нет вопросов» передаёт ход дальше. После круга с ведущим голосование начинает ведущий, по таймерам начинается сразу.
5. **Голосование.** Из игры выбывает один человек, всегда. Ничья решается одним дополнительным голосованием между лидерами, дальше жребием. Карта защиты «Адвокат» снимает один голос.
6. **Итог раунда.** Выбывший показывает роль и открытые пункты карточки, продолжает писать в журнал, но не голосует и не рассказывает. Резинка баланса: если выбыл невиновный, «Экспертизу» получает случайный невиновный (на шестерых двое); если выбыл преступник, а второй ещё в игре, он получает «Ложный след»: первая «Экспертиза» или «Обыск», которые выдали бы его, покажут чистый результат.

Финал (раунд 4): улика → рассказы → обсуждение → допрос → тайное голосование за троих подозреваемых → по очереди защита каждого → два итоговых голосования подряд (по одному исключению) → приговор. Всего пять исключений: по одному в раундах 1–3 и два в финале. Невиновные побеждают, только если исключены и убийца, и сообщник; если хоть один остался, побеждают преступники. Преступники выигрывают и досрочно, как только их становится столько же, сколько невиновных (2 на 2, 1 на 1). Если после раунда осталось трое или меньше, партия сразу переходит в финал. Правило `settings.rules.gang` (по умолчанию включено) возвращает прежний вариант: сообщник только при 8+, исключить нужно одного убийцу, в финале одно исключение и последний шанс сообщника.

Карты: у каждого одна из колоды, в колоде всегда две «Подмены улики» у случайных игроков (кто угодно, не только преступники). «Подмена» тайно меняет именно ту улику, которую найдут следующей, так, что она указывает на выбранного игрока и не указывает на того, кто подменил (если две подмены попали в одну улику, остаётся последняя); найдут её в начале следующего раунда, как обычную, а в итогах видно, кто подменил и какая была настоящая улика. Разбор и замеры баланса: `docs/cards-design.md`, тест `scripts/test-cards.js`.

Очки: победа команды, спрятанная тайна, личная цель, голос за убийцу, сообщник. Награды: лжец, шерлок, открытая книга, подставщик. В конце хронология вечера «Дело закрыто» и сезонная таблица.

Режимы хода: **Ведущий** (таймеры мягкие, фазу меняет «Дальше», кнопка «+30 с» добавляет время) и **Таймеры** (фазы меняются сами). Если ведущий пропал, включается автопилот.

Дела собраны в паки (`PACKS` в `cases.js`). Пока пак один, «Основной», в нём 15 дел; в лобби ведущий выбирает пак, а дело из него выпадает случайно при старте и не повторяется подряд в одной комнате. Дела первых версий (20 штук) убраны из архива: при смене `PACK_REV` сохранённый `cases.json` один раз очищается от них, дела, добавленные админом, остаются и попадают в основной пак. Новые встроенные дела добавляются в сохранённый архив один раз, удалённые админом не возвращаются. При смене `TEXT_REV` названия, жертвы, вводные и профессии встроенных дел один раз обновляются и в сохранённом архиве (правки админа в этих полях затираются).

Уникальность партий: карточки каждый раз собираются заново из больших пулов (по 18 профессий в деле плюс 16 общих, 40 связей, 40 мотивов, 14 привычек, 20 и 24 секрета, по 7 мест), а улики выбираются из 22 тегов. Проверка в `scripts/test-pack.js`: одна и та же карточка в двух партиях одного дела встречается реже чем в 1% случаев.

Улики генерируются так, чтобы дело всегда решалось: каждая подходит 2–3 игрокам, включая невиновного. Как устроены улики в банде, описано ниже. Это проверяет `scripts/test-generator.js`.

## Discord

В лобби ведущий вставляет приглашение (`discord.gg/…`, `discord.com/invite/…`). Принимаются только ссылки Discord, иначе сервер их отклонит. У всех появляется кнопка «Открыть Discord» в лобби и в верхней панели игры.

## Админка

`/#/admin`, вход по `ADMIN_KEY`.

- **Тестовая комната.** Боты от 3 до 9, дело, ваша роль, режим хода (ведущий или таймеры), скорость до ×20, автопилот за вас. В партии «Пульт теста»: пауза, пропуск фазы, скорость, «Играть за» любого игрока, режим бога (роли, карточки, карты, улики, сид), перезапуск с тем же сидом.
- **Комнаты.** Все комнаты сервера: пауза, пропуск, скорость, бот, «Все готовы», старт, закрыть.
- **Дела.** Редактор архива и проверка улик на 300 раскладах.
- **Симуляция.** Боты играют до 300 партий: доля побед, выбытия по раундам, нарушения правил.

## Устройство

```
server/auth.js  вход через Discord и Google, подписанные сессии
public/shared   логика для сервера и браузера: rng, content, cases, generator, engine, bots, hub
public/js       клиент: net, ui, home, lobby, game, end, admin, app
public/css      app.css (тёплый нуар)
server/index.js Express + Socket.IO, подключает сокеты к Hub
scripts         тесты и прогоны в браузере
```

`Hub` не знает про сеть. Демо-режим (`dist/detective-preview.html`, `npm run preview`) вызывает его прямо в браузере, соседи по комнате там боты.

```bash
npm test                         # генератор, движок, хаб

AUTH_DEV=1 ./scripts/dev.sh && node scripts/e2e-presence.js   # возврат и закрытие комнаты в браузере
./scripts/dev.sh                 # перезапуск локального сервера
node scripts/e2e-game.js         # 6 живых вкладок: вся партия до финала
MODE=timers node scripts/e2e-admin.js   # админка и партия через интерфейс (MODE=host по умолчанию, MOBILE=1 для телефона)
node scripts/tour.js             # экскурсия по экранам для скриншотов
node scripts/demo-check.js       # демо без сервера
node scripts/strategy-lab.js 600 # лаборатория стратегий: модели игроков и убийцы, таблицы побед (отчёт: docs/strategy-analysis.md)
```

Для e2e нужен Playwright с Chromium (`CHROME` задаёт путь к браузеру).

Баланс с ботами: невиновные выигрывают около 77% при 6 игроках, 48% при 8 и 43% при 10. Живые игроки обычно сильнее ботов, поэтому цифры стоит перепроверить на настоящих партиях.


## Банда

Улики строит генератор для двоих: убийце подходят три улики из четырёх, сообщнику тоже три (две общие, по одной своей), вместе они закрывают все четыре. Каждой улике подходят 2–3 игрока, среди них хотя бы один невиновный. У невиновных есть двойники с тремя совпадениями (один за столом до 7, двое от 8), а всем четырём уликам не подходит никто, поэтому совпадения не приговор и решают алиби и слова. Особенностей у всех 2–3, так что по их числу преступника не вычислить. Проверка: `node scripts/test-generator.js`, правила финала: `node scripts/test-gang.js`. Расчёт баланса: `docs/multi-criminal.md` (абстрактная модель, `scripts/crime-lab.js`) и замер на настоящем движке через `scripts/strategy-lab.js`.
